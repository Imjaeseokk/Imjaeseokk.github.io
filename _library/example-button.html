--- title: Button — HTML example category: ui-components description: HTML로 작성한 버튼 미리보기와 소스 복사 예제입니다. ---

실제 버튼을 미리 보고, 아래에서 같은 HTML 소스를 복사할 수 있습니다.

HTML

<button type="button" style="padding:12px 20px; border:0; border-radius:8px; background:#3366FF; color:white; cursor:pointer;">Example button</button>

HTML 파일에서 소스를 글자로 보여주려면 <와 >를 각각 &lt;, &gt;로 작성합니다.
